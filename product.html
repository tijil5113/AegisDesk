Product

The environment, then the applications

AegisDesk is a web OS shell with a suite of applications. It does not replace your computer’s operating system. It is a coherent workspace that runs in the browser.

Window management

Applications open as windows with focus, resize, and restore. Several apps load their full page inside that window.

Launcher

Alt+Space opens the application launcher. Icons are shared with the taskbar and this website.

Search

Ctrl+K opens the command palette. Local search covers apps, commands, notes, tasks, files, and help. Ask Aegis is opt-in per query.

Personalization

Themes, motion, notifications, and related preferences persist through Settings.

Mail

Compose To, Cc, Bcc, subject, and message. Sending uses the server mail provider. Status is Sending, Sent, or Failed.

Music

Search YouTube through the server API and play results in the AegisDesk player. Audio is not extracted or downloaded.

Tasks & Notes

Create, edit, complete, and search local work. Data stays in this browser under existing storage keys.

Files & Calendar

Files is a virtual workspace. Calendar stores local events. Google Calendar sync is not enabled.

AI & News

AI Assistant remains a conversation app. Aegis Intelligence routes supported actions with confirmation for mail drafts. News uses configured server providers.

Developer tools

Terminal is a simulated shell with safe commands. Code Editor is a lightweight editor. Code execution is limited to what the browser actually supports.
