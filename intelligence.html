Aegis Intelligence

Tell AegisDesk what you want. Stay in control.

Aegis Intelligence is a system command surface, not a pile of extra AI buttons. Known commands run locally. Natural language is mapped only to registered actions. The model cannot execute code or send email by itself.

Available now

  • Command palette (Ctrl+K) for apps, commands, notes, tasks, files, and help
  • Deterministic phrases such as “Open Calculator” or “Switch to dark theme”
  • Constrained AI intent that must match the action registry
  • Mail compose drafts that you send
  • Note → task and Ask Aegis previews before anything is created
  • Quick Look, Activity Center, clipboard history, Focus Mode, Spaces, and session restore

Honest limits

  • Clipboard history is AegisDesk copies, not the computer clipboard
  • Files are a virtual workspace, not host-disk access
  • AI is unavailable when the provider is not configured — local commands still work
  • File attachments in Mail are not sent in this version
