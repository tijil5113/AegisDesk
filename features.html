Features

Shipped capabilities

This list is limited to behavior that exists in the current AegisDesk product.

Window management

Applications open, focus, move, and resize inside the AegisDesk shell.

Launcher

Browse and launch the application suite from one menu.

Search

Find applications from the desktop search field.

Personalization

Theme, motion, and notification preferences persist locally.

Mail

Compose and send through the server mail provider, with local sent history.

Music

YouTube search and in-app playback. No audio extraction.

Tasks

Create, edit, complete, filter, and persist tasks in this browser.

Notes

Write, search, and autosave notes locally.

Files

Virtual files and folders in browser storage — not unrestricted disk access.

Calendar

Local month view and events. External sync is not enabled.

AI

Standalone assistant via the server OpenAI integration.

News

Headlines from configured server news providers.

Developer tools

Simulated terminal and a lightweight code editor.
